Payload publishing model

Payload changes document state. The public application chooses the delivery moment.

Document states

StateMeaningPublic behavior
DraftEditorial work not approved for readers.Require authenticated preview access.
PublishedThe current public version of a document.Readable through public REST access.
ChangedA published version exists with a newer draft.Readers keep seeing the published version.

Keep separate: public delivery reads only published content; editorial preview reads drafts through an authenticated path.

Decision shortcut

  • If “news unavailable” is acceptable during an outage, evaluate browser-runtime REST first.
  • If old news must remain visible, evaluate static-build or hybrid delivery.
  • If per-request server logic is needed for other reasons, then evaluate server runtime.
